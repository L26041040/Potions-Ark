# 用一組共享密碼加暱稱，不做個人帳號

倉庫只有三到六位彼此認識的股東使用，目標是最快交付，而且股東明確不想註冊帳號。所以整個網站只用一組共享密碼進出，股東自己填一個暱稱，暱稱不經驗證，所有股東權限相同。

## Consequences

- 留言與狀態異動上的暱稱只是自稱，無法防止冒名，也無法針對單一股東撤銷存取。有人不該再進來時，只能更換共享密碼，所有人都要重新登入。
- 沒有「誰能刪除」「誰能改狀態」的區別。防誤刪靠的是回收桶，不是權限。
- 不提供免密碼的邀請連結。物件直達連結可以分享，但未登入者仍須輸入共享密碼。
- 日後若要加個人帳號，現有紀錄上的暱稱只是文字，無法對應回帳號。
