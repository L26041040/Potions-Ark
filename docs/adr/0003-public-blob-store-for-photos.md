# 照片放在公開的 Blob store，靠不可猜的網址保護

> 已不適用。規格 v2.0 起不再儲存任何照片，也不使用 Vercel Blob；封面直接顯示原站的圖片。以下內容僅作為紀錄保留。

網站本身在共享密碼之後，照片卻放在不需密碼就能開啟的公開 Blob store，網址帶隨機字尾、無法被列舉。這是刻意的：照片絕大多數本來就公開在刊登上，而私人 store 會讓每一張照片都要經過一支驗證程式或會過期的簽章網址，圖庫變慢、不能直接產生縮圖、程式也更多，換到的只有「外流的照片網址打不開」，對刊登照片沒有實質意義。本專案的第一優先是快速看照片。

## Consequences

- 拿到某張照片網址的人，不需共享密碼就能看到那一張。更換共享密碼不會讓既有照片網址失效，刪除照片才會。
- 照片網址只能出現在登入後才拿得到的頁面與回應裡。登入頁、未登入時的任何回應、連結預覽標籤都不得包含照片網址。
- 不適合存放合約、證件等機密文件，上傳介面要提示這一點。日後若真有這類需求，另開一個私人 store，而不是把現有 store 改成私人。
- store 的公開或私人屬性建立後不能更改；要改只能新建 store、搬移檔案並改寫資料庫中的網址。
